# Autofill Application Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:subagent-driven-development or superpowers:executing-plans. Steps use `- [ ]` syntax.

**Goal:** Two-phase apply flow — upload docs → parsed prefill with "auto-filled ✓" badges + source attribution + cross-doc warnings → confirm checkbox → create application. Spec: `docs/superpowers/specs/2026-08-08-autofill-design.md`.

## Global Constraints
- `doc_intel.extract_document` is the parser (deterministic, no Celery latency); `doc_intel.check_consistency` for name warnings.
- Prefill lives in `request.session["apply_prefill_<advt_id>"]` (session-only; no new models); cleared on successful submit and on fresh GET.
- `confirm=on` required ONLY when a prefill exists — existing `test_apply_flow` (no session) must still pass unchanged.
- Existing apply flow (post_id + resume + declare + certs) preserved in phase 2.
- Python: `.venv/Scripts/python.exe`; pytest `--reuse-db` + 30s retry (max 3); no migrate/full suite. Commit `Phase 2: Autofill — parsed-doc prefill with badges and consistency warnings`.
