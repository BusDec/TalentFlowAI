# Phase 4 Implementation Plan (15 Independent Items)

> **For agentic workers:** Use subagent-driven-development. Steps use `- [ ]`.

**Goal:** Ship all 15 Phase 4 items. Spec: `docs/superpowers/specs/2026-08-08-phase4-design.md`.

## Global Constraints
- New models tenant-schema; `migrate_schemas` at batch verification.
- External integrations: mock/stub default; real raises `NotConfigured` when env absent.
- Python: `.venv/Scripts/python.exe`; pytest `--reuse-db` + retry. Each agent: 1 commit per item.
