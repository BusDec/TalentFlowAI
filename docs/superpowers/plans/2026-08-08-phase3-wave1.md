# Phase 3 Wave 1 Implementation Plan (Roster, Fee, Notifications)

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:subagent-driven-development or superpowers:executing-plans. Steps use `- [ ]` syntax.

**Goal:** Persistent DoPT 100-point roster per post, fee payment + exemption engine (mock gateway), and an email/SMS notification outbox with console provider. Spec: `docs/superpowers/specs/2026-08-08-phase3-wave1-design.md`.

## Global Constraints
- New models in tenant apps only; `migrate_schemas` (not `migrate`) after model changes, at final verification.
- External adapters degrade: mock/console providers default; real providers raise `NotConfigured` with a clear message when env keys are absent — never a crash.
- LLM/network-free tests: all provider paths deterministic.
- Python: `.venv/Scripts/python.exe`; pytest `--reuse-db` + 30s retry on DB lock (max 3). Commits: `Phase 3: Roster — …` / `Phase 3: Fee — …` / `Phase 3: Notify — …`.
